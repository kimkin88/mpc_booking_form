# Quick Start — MPC Booking (Administrators)

Get productive in about five minutes.

## 1. Sign in (30 seconds)

1. Open the app → **Sign in**.
2. Enter your admin email and password.
3. You land on **Bookings**.

## 2. Create a booking (1 minute)

1. Click **New Booking**.
2. Confirm the **SB Number** (or Regenerate).
3. Enter Brand, Campaign, Client, Budget/Currency if known.
4. Create — the booking workspace opens.

## 3. Fill essentials (1–2 minutes)

On **Details**:

1. Set **Budget** and check the **Rate card** (half / full day).
2. Add **Client** name + email (needed for reminders).
3. Add at least one **Preferred shoot day** if you know it.
4. Click **Save Booking**.

Optional: upload a media plan under Files → use **Autofill from documents**, review, then apply.

## 4. Share the client portal (1 minute)

1. Open **Portal & Permissions**.
2. **Generate Link**.
3. Optionally set a **PIN** and expiry.
4. Mark must-have fields as **Required**.
5. **Copy link** and send it to the client.

## 5. Monitor (ongoing)

- Header **bell** — client opens, edits, uploads.
- **Sent Links** — find any portal URL again.
- **Calendar** — live formats + shoot days; select a day → **pencil** to edit.
- Header **?** — short how-to tips anytime.

## Done when…

Client clicks **Submit** (or required items complete) → status moves toward **Ready for Review** → you review and set the next status.
